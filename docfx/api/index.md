# API reference

This page covers the public types of `Savepoint.Core`, generated from the doc comments in the code. The app uses the core only through the interfaces in `Savepoint.Core.Api` (`IGamesApi`, `ISettingsApi` and the rest). The other namespaces hold the records and errors those interfaces pass around.

Each interface's comments state its contract: what it returns, what it refuses, and which errors it reports. The [architecture guide](../../docs/architecture.md) shows how the layers fit together.
