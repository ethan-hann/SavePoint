# SavePoint

SavePoint keeps the setup that works. It takes snapshots of an installed game, its mods and its saves, and restores any of them in one step.

- [User guide](../docs/user-guide.md): add a game, snapshots, profiles, Go back, and Free up space.
- [Developer guide](../docs/developer-guide.md): build, test and package SavePoint.
- [Architecture](../docs/architecture.md) and [Decisions](../docs/decisions.md): how the code is organized and why it behaves as it does.
- [API reference](api/index.md): the public contract of `Savepoint.Core`, the layer the app is built on.

The source, releases and issues are at [git.tortal.tech/ethan-hann/SavePoint](https://git.tortal.tech/ethan-hann/SavePoint). These pages are built from `main`, so they describe the newest code, which can be ahead of the latest release.
