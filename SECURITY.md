# Security

SavePoint runs on your own computer, changes only the folders you give it, and makes no network requests except the optional artwork lookup on Steam. The parts most worth a second look are path safety (the folders SavePoint refuses to take over), the bundled git and how it is run, and anything that could make SavePoint delete or overwrite files outside a game's folders.

## Reporting a problem

Please do not put the details of a vulnerability in a public issue. Open an issue titled "Security contact request" with no details, and the maintainer will reply with a private way to send them. Expect a first reply within a week.

## Supported versions

SavePoint is pre-release. Only the latest release and `main` get fixes.
